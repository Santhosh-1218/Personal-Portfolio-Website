Hackathon Project

WarehouseIQ (StackFlow)

Hosted by Work Wizards Innovations x Hack2Skill x Google for Developers

Project Overview

WarehouseIQ is an intelligent inventory & warehouse management platform designed to solve real-world warehouse operations and order fulfillment challenges. Instead of just displaying data, WarehouseIQ focuses on decision-making — detecting operational problems, determining appropriate actions, executing workflows, and tracking resulting impact.

Key Features & Capabilities

  • Real-time Stock Monitoring: Instant tracking of inventory and stock allocations.
  • Smart Order Prioritization: Automated fulfillment workflows based on order urgency.
  • Inventory Contention Resolution: AI analyzes priorities and resolves stock shortages when urgent orders exceed available inventory.
  • Picking, Packing & Quality Control: Streamlined QC workflows and dispatch tracking.
  • Financial & Revenue Intelligence: Real-time insights into revenue, loss, and profit analytics.

Full-Stack System

Student Management System

Built with Python, Flask, Firebase Authentication & OpenPyXL

Project Overview

A full-stack web application designed to efficiently manage student records. Built with Python and Flask for backend logic, it integrates Firebase Authentication to provide secure user login, registration, and password recovery. Student details filled out on the web interface are automatically written, synchronized, and saved into Excel files using the openpyxl library.

Key Features & Workflow

  • Firebase Authentication: Secure user registration, login, and password recovery system.
  • Student Form & Dashboard: Clean web UI to fill student details, view records, and manage student data.
  • Automated Excel File Storage: Real-time automated data writing and updating to Excel spreadsheets via openpyxl.
  • Persistent & Structured Storage: Ensures accurate student data management and easy export for institutional use.
